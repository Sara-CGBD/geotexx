# 👥 User Access Instructions - GEOCIL Automation System

## **For End Users (No Installation Required!)**

---

## **✅ What You Need:**

- ✅ A computer/laptop (Windows, Mac, or Linux)
- ✅ A web browser (Chrome, Firefox, Edge, or Safari)
- ✅ Internet connection (same network as server, or internet for cloud)
- ✅ Your login credentials (username and password)

## **❌ What You DON'T Need:**

- ❌ XAMPP (not required)
- ❌ Any software installation
- ❌ Any configuration
- ❌ Technical knowledge

---

## **🚀 How to Access the System:**

### **Step 1: Open Your Web Browser**

Open any web browser:

- Google Chrome (recommended)
- Mozilla Firefox
- Microsoft Edge
- Safari (Mac)

### **Step 2: Enter the Access URL**

Type or paste this URL in the address bar:

```
http://[SERVER_IP]/geotexx
```

**Example:**

```
http://192.168.1.100/geotexx
```

**Or if using domain name:**

```
https://geocil.yourcompany.com
```

### **Step 3: Login**

1. Enter your **Username**
2. Enter your **Password**
3. Click **"Login"** button

### **Step 4: Start Using the System**

Once logged in, you'll see the dashboard with your assigned modules.

## **❓ Troubleshooting:**

### **"This site can't be reached"**

**Possible causes:**

- ❌ Not on the same network (for local server)
- ❌ Server is down
- ❌ Wrong URL

**Solutions:**

- ✅ Check you're on the correct network
- ✅ Verify the URL is correct
- ✅ Contact IT support

### **"Connection timed out"**

**Possible causes:**

- ❌ Server is not running
- ❌ Firewall blocking

**Solutions:**

- ✅ Contact IT administrator
- ✅ Check if server is online

### **"Access Denied" or "403 Forbidden"**

**Possible causes:**

- ❌ Wrong URL
- ❌ Server configuration issue

**Solutions:**

- ✅ Verify URL is correct
- ✅ Contact IT support

### **"Invalid Username or Password"**

**Possible causes:**

- ❌ Typo in username/password
- ❌ Caps Lock is on
- ❌ Account is disabled

**Solutions:**

- ✅ Check Caps Lock
- ✅ Verify username and password
- ✅ Contact IT to reset password
